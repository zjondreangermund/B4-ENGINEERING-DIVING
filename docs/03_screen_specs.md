# Screen Specifications

## 1. Login Screen
Purpose: Secure access for B4 staff.

Fields:
- Email
- Password
- Company workspace

## 2. Executive Dashboard

Top KPI cards:
- Revenue excl. VAT
- Gross profit
- Gross profit %
- Jobs
- Hours
- Labour cost
- Equipment cost
- Workshop cost

Charts:
- Profit by division
- Revenue vs costs by month
- Jobs by OPS manager
- Cost breakdown

Filters:
- Year
- Month
- FY
- Division
- OPS manager

## 3. Job Register Screen

Table columns:
- Job No.
- Date
- Client
- Description
- Division
- OPS manager
- Invoice No.
- Revenue excl. VAT
- Total costs
- Profit
- Status

Actions:
- Add job
- Import Excel
- Export Excel
- View job
- Edit job
- Generate job card

## 4. Job Details Screen

Sections:
- Job information
- Revenue and invoice details
- Time and hours
- Labour allocation
- Equipment allocation
- Workshop costs
- Uploaded documents/photos
- Audit history

## 5. Import Screen

Steps:
1. Upload workbook
2. Detect sheets
3. Map columns
4. Validate rows
5. Show errors/warnings
6. Import to staging
7. Approve import

## 6. Mobile Field Capture

Simplified mobile workflow:
1. Select/create job
2. Start work
3. End work
4. Add notes/photos
5. Client signature
6. Submit

This should be added after the web job register and dashboard are stable.
